# VaxTweaker

Official downloads of VaxTweaker for Windows 11 (64-bit). It also installs on Windows 10 22H2, without promised support.

- Website, plans and support: https://vaxtweaker.com
- Download page: https://vaxtweaker.com/download

Each release has one file, the Windows installer. Its SHA-256 is written in the release notes and on the Download page, and the two must match.

Only download VaxTweaker from vaxtweaker.com or github.com/vaxead. We never send files by DM or in chat.
